Commutation

2026 · Personal project Next.js · Supabase Realtime · Row-level security Built for one Saturday

A real-time party app for six people, built for one Saturday. Before the day it is an info hub and a private survey; on the day it becomes a synced multiplayer game console — about 25 games across three halls, on six phones and an optional TV.

Play the demo Summary Overview

Summary Overview

A personal project. The demo uses a made-up crew and made-up answers — none of my friends' real answers appear anywhere.

The one rule

Survey answers are readable only by their author — not by the other players, not by the host, not through the API. That is enforced by row-level security in Postgres, not by convention. The hub shows everyone's answer count so people can chase each other, never the content, and answers are released by the game engine only inside a live round. The reveals only work on the day if nobody has read them first.

What's in it

  • The Vault runs on the survey answers (“Who Wrote It?”, “Know Me Best”); the Huddle is phones-as-buzzers; the Arena puts a game on the TV with phones as controllers.
  • Halls unlock automatically at the start time; a board keeps score all day and the awards close the night.
  • Original poster-style key art, and a hand-built SVG tile for every game.

Is a personal app worth a portfolio slot?

I think so: it is a complete product with real users, real-time sync across devices, and a privacy rule that had to hold under a deadline. The demo recreates the hub, the survey, two playable games and the board on one device.
