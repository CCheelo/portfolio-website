Personal project

A private iOS app for two people.

Games, a shared question of the day, a ranked date planner, a memory scrapbook and gamification — synced live between both partners' phones.

  • Answer the question of the day to unlock your partner's answer.
  • Drag your Top 5 dates into order, then rate one together.
  • Spin the Lucky Wheel and play Would You Rather.

How it's built

SwiftUI + Supabase, no Mac

Native for iOS 17 with @Observable and async/await, backed by Supabase Postgres, Realtime, Storage and Auth, with row-level security per couple.

  • Built without owning a Mac: every build runs on a GitHub Actions cloud Mac and ships a sideloadable app.
  • Offline last-state restore and free local notifications, no paid push service.
  • This page is a web reproduction for the portfolio; the real thing is SwiftUI.
