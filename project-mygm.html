MyGM

2026 · Personal project React · TypeScript · Vite · Playwright Version 1 playtest

A basketball management game that combines the depth of a football-manager-style sim with a modern GM mode: build the roster, run the franchise, and compete for championships.

Play the game Summary Overview

Summary Overview

What you do

  • Manage the team — roster building, trades with AI teams, free agency and contract extensions, game plans and tactics, morale, fatigue, injuries and player development.
  • Run the franchise — finances and the salary cap, ticket, concession and merchandise prices, facilities, sponsorships and arena operations.
  • Compete — simulate seasons and playoffs, follow standings and league news, and meet the board's and the fans' expectations.
  • Analytics — detailed player stats and ratings, team performance tracking, financial reports and scouting.

How it's built

React and TypeScript on Vite, with end-to-end tests in Playwright and deployment on Vercel. A simulation game is mostly a data and modelling problem — player ratings, contract economics and season simulation all have to stay believable together, which makes it a surprisingly good analytics workout.

Status

Version 1 is fully playable — start a new dynasty above. A playtest round is collecting feedback before the next set of features. Team names and logos belong to their owners; this is a non-commercial fan project.
