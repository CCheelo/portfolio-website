Summary Overview

The Platform

PRC System is a multi-page web application for managing football academies and their players. The platform includes authentication, an academies dashboard, player listings, individual profile pages, and a data center for awards and competition outcomes.

Tech Stack

  • → Frontend — HTML, CSS, JavaScript, Bootstrap
  • → Backend — Firebase (authentication, Firestore database, storage)
  • → Data — JSON-structured player, academy, and award records

Team Structure

The project is split across two teams: Frontend (HTML, CSS, JavaScript, Bootstrap, and UI/UX design) and Backend (Firebase authentication, Firestore database, and storage). Both teams use a feature-branch Git workflow with PRs into dev, with a single project lead merging dev into main for stable releases.

My Role

Project Manager — gathering requirements with the organisers, leading the frontend team across all HTML, CSS, JavaScript and UI/UX work, and coordinating with the backend team through to launch and handover. Responsibilities include coordinating task assignments, reviewing and merging frontend PRs, enforcing design consistency, and ensuring the frontend integrates cleanly with the backend team's Firebase implementation.

Also responsible for stakeholder engagement on behalf of the project — including presenting progress and demos to the company CEO and pitching the platform to potential football academies.

Status

Live, and handed over to the owners, who now run it independently. Built internally as the “PRC System” (Player Registry Centre). An interactive demo is available above — it runs on anonymized dummy data and mirrors the live platform: a public homepage with a live match centre, the admin dashboard, the player registry, individual player profiles, the academy database, a historical archive, and the player registration flow.
