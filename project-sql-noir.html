SQL Noir

2026 · Personal project JavaScript · sql.js (SQLite in WebAssembly) · CodeMirror Playable

Lusaka, 1974. Victor Kasonde, lead guitarist of Broken String, is found strangled in an alley. You are a CID detective and the precinct database is yours — write SQL, follow the evidence, and file an accusation.

Play the game GitHub Code Summary Overview

Summary Overview

How it plays

  • A real SQLite database runs in your browser (sql.js, compiled to WebAssembly) — no server, and after the first load it works offline.
  • You discover the columns by querying; leads open as you uncover evidence, and a detective's notebook records what you have found.
  • A syntax-highlighting SQL editor (CodeMirror), hints when you are stuck, and progress saved in the browser.

Why I built it

SQL is the skill I use most and the one people find most intimidating to start. A mystery gives every query a reason to exist: you write a JOIN because you need to know who was at the club that night, not because an exercise told you to.

The case lives in two JSON files and a build script that regenerates the seed data, so a new suspect or clue is an edit, not a rewrite.
