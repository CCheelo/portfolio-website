2026 · Personal project SwiftUI · Supabase · GitHub Actions Private app for two

A private iOS app for two people — games, a shared question of the day, date planning, a memory scrapbook and gamification, all synced live between both partners' phones.

Try the web demo Summary Overview

Summary Overview

A personal project. The demo is a web recreation of the app's main screens for a made-up couple — no real messages, photos or answers are shown.

Features

  • Home — partner status, a days-together counter, a daily streak, a shared question of the day with a blind reveal, and quick sends.
  • Games — Would You Rather, trivia about each other, a lucky wheel, custom and weekly challenges.
  • Dates — a ranked Top 5 with drag-to-reorder, “Surprise me”, and a three-step rating that both partners complete, feeding a leaderboard of your best dates.
  • Memories — a shared album, collections, a timeline and a polaroid scrapbook, with milestones linked automatically.
  • Gamification — points, levels, streaks with repair, and badges.

Built without a Mac

Native SwiftUI for iOS 17 using @Observable and async/await, on Supabase for Postgres, Realtime, Storage and Auth, with row-level security per couple. I don't own a Mac, so every build runs on a GitHub Actions cloud Mac and ships a sideloadable app; notifications are local, so there is no paid push service.
