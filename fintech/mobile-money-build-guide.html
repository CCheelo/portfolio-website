1. The data — all free, no login

Use Global Findex as your backbone, GSMA for the growth/transaction story, and Bank of Zambia for the local deep-dive.

A. World Bank Global Findex 2025 — primary dataset ★

The cleanest, most dashboard-ready source: one spreadsheet, ~300 indicators, 141 economies, survey waves 2011→2024.

  • Download: worldbank.org/en/publication/globalfindex/download-data → grab GlobalFindexDatabase2025.xlsx (also .csv / .dta).
  • Contains: account ownership, mobile money account ownership, broken down by gender / income quintile / rural / age / education — covers your "inclusion gaps" and "benchmarking" questions. Includes a Sub-Saharan Africa aggregate row and a Zambia row, so benchmarking is just a filter, not a join.
  • This single file answers 3 of your 4 key questions on its own.

B. GSMA Mobile Money Metrics — time-series / transaction value

  • Page: gsma.com/mobile-money-metrics (interactive dashboard; JS-rendered, open in a browser). Export the country/region series to CSV from the dashboard.
  • Contains: registered vs active accounts, transaction value & volume, agents — annual, by country and region. This is your "adoption over time" and "transaction value" series.
  • Headline context: global mobile-money transactions hit $2T in 2025, ~2B registered accounts, 500M+ monthly active users (GSMA SOTIR 2025).

C. Bank of Zambia — Zambia-specific numbers

  • Stats portal: boz.zm/payment-systems-statistics.htm (JS-rendered, open in a browser).
  • Annual reports (direct PDFs, easiest): 2023 NPS Annual Report, 2022 NPS Annual Report.
  • Anchor figures: 14.65M registered wallets, 12.33M active wallets (2024); ~4.07B transactions, +9.4% YoY.
Scope tip: If pulling all three feels heavy, ship v1 on Global Findex alone (clean, comparable, instant) and add the GSMA time-series and a BoZ Zambia tab as v2. Your project page already frames all four questions, so a Findex-only v1 still delivers a complete-looking dashboard.

2. Prep the Findex file (about 15 min)

The Findex Excel is wide (one column per indicator). Two options:

  • Easiest: open the Data sheet, keep only the columns you need (Country name, Country code, Region, Income group, Year, plus the mobile-money / account-ownership indicators and their gender/rural/income breakdowns), save as findex_clean.xlsx.
  • Better for charts: unpivot the indicator columns into long format (Country | Year | Indicator | Value) — do this inside Power BI with Power Query (next section), so you never hand-edit the data.

3. Build the Power BI report (step by step)

Step 1 — Get data

Home → Get data → Excel workbook → select GlobalFindexDatabase2025.xlsx → in the Navigator pick the Data sheet → Transform Data (opens Power Query).

Step 2 — Clean in Power Query

  • Use First Row as Headers if needed.
  • Keep relevant columns (right-click unneeded columns → Remove).
  • Select the indicator value columns → Transform → Unpivot Columns → rename the new columns to Indicator and Value.
  • Set types: Value = Decimal, Year = Whole number.
  • Repeat Get data for the GSMA CSV (a second query) — same long shape: Country | Year | Metric | Value.
  • Close & Apply.

Step 3 — Model

  • Build a small DimCountry table (Country, Region, Income group) and relate it to both the Findex and GSMA queries on Country code. This lets one slicer filter both sources.
  • Add a DimYear table if you want a clean time axis.

Step 4 — Core measures (DAX)

Mobile Money Ownership % =
    CALCULATE( AVERAGE('Findex'[Value]),
        'Findex'[Indicator] = "Mobile money account (% age 15+)" )

Account Ownership % =
    CALCULATE( AVERAGE('Findex'[Value]),
        'Findex'[Indicator] = "Account ownership (% age 15+)" )

Gender Gap (pts) =
    [Account Ownership % Male] - [Account Ownership % Female]

Swap the indicator strings to match the exact labels in your file.

Step 6 — Polish

  • Consistent titles, data labels on key visuals, a "Source: World Bank Global Findex 2025 / GSMA" footnote text box.
  • Test that the slicers cross-filter all pages.

4. Publish & wire it into your portfolio

  • File → Publish → To Power BI (web) → pick a workspace.
  • In the service, open the report → File → Embed report → Website or portal → copy the https://app.fabric.microsoft.com/view?r=… URL.
  • In project-fintech.html: delete the "publishing soon" placeholder <div>, uncomment the prepared <iframe> block, and paste that URL into the two marked spots (the iframe src and the "Open in Power BI Service" link).
  • Optionally add the Full Report (PDF) and GitHub Code buttons from the commented stub in the hero (export the report to PDF; push the .pbix + cleaned data to a mobile-money-fintech repo).
  • Commit & push — Vercel auto-deploys.
